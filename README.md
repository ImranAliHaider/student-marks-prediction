# student-marks-prediction
A machine learning project that predicts student marks based on daily study hours using Linear Regression. Built with Python, Pandas, Scikit-learn, Matplotlib, and Streamlit. Includes model evaluation metrics, data visualization, and an interactive web application. Uses synthetic sample data for learning purposes.


**Features**

Predicts student marks based on study hours.

Uses Linear Regression for prediction.

Displays a graph of actual marks and the regression line.

Provides an interactive web application using Streamlit.

Evaluates model performance using MAE, RMSE, and R² score.

**Technologies Used**

Python

Pandas

Scikit-learn

Matplotlib

Streamlit

**Project Files**

app.py — Interactive Streamlit application.

train_model.py — Trains and evaluates the Linear Regression model.

student_marks.csv — Sample dataset.

requirements.txt — Required Python libraries.

**How to Run the Project**

Install Python on your computer.

Install the required libraries:

python -m pip install -r requirements.txt

Run the model training program:

python train_model.py

Start the web application:

python -m streamlit run app.py

Open the local URL shown in the terminal.

**Dataset**

The project uses sample data containing daily study hours and student marks. This data is for educational purposes.

**Learning Objective**

The main objective is to understand Linear Regression, model evaluation, data visualization, and building a simple Machine Learning application.
